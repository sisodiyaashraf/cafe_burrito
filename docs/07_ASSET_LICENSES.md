# Asset License Tracker

## Rules
- Only CC0 or CC-BY (or equivalent permissive open-source licenses such as SIL OFL) assets are allowed.
- No NC (non-commercial) or ND (no derivatives) licenses are permitted under any circumstances.
- Every asset must be logged in this tracker before it is added to `assets/`.

## AI-generated assets
When an asset is generated using an AI tool:
- Record the tool name (e.g. Midjourney, DALL-E 3, Stable Diffusion).
- Record the generation date.
- Record a link or screenshot reference to the tool's commercial terms of service in effect at that date.
- Record the exact prompt and style-lock parameters used to generate the asset.
